# 主题发现 · 单人设计审核

审核对象为 02b 规格、现有 pull/record/选题入口和编辑端的互斥提交。原参考项目按账号推进水位适合持续订阅，临时主题采样没有可复用的账号水位。

| 走查项 | 对比及决定 |
|---|---|
| X | 官方 recent search 支持跨作者主题和公开互动字段，采用服务端单页调用。Chrome 扩展依赖终端安装、登录状态与页面结构，此次无需维护第二套入口。 |
| 公众号 | 已有公众号草稿接口解决自有号的草稿投递。跨号发现采用独立网页索引，强制限制与校验文章域名、地址结构。索引覆盖率未知，时段来自搜索服务的 freshness 筛选，原文日期不可推断。 |
| 次数与恢复 | UI 锁只能防本标签双击。使用数据库唯一请求号，在外呼前提交占位；任何重放返回冲突。进程意外退出的 pending 回执保留，不自动补打可能已计费的调用。 |
| 存储和归属 | 复用原有来源去重和审计。预览使用有时效、绑定账号的签名，同一编辑可复选。公众号的搜索标题/摘要只供现场筛选，持久数据使用原文链接和编辑自行核对输入。 |
| 可解释性 | X 中位数使用完整四项互动，无指标以空值区分。公众号保留索引顺序，归一后统计各词在可见标题或摘要的篇数。两个采样框独立呈现。 |
| 可验证性 | 验证请求参数、固定目标、凭证缺失、失败/空集、响应类型、并发重放与选择入库；以浏览器从检索进入素材库。真实凭证联调另记。 |

**设计结论：通过，允许实施 02b。** 审核性质为独立开发者自审。批准范围为手动触发的两路发现、样本分析和显式入库。
