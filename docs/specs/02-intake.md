# 02-intake · 来源、观点和选题

## 业务契约

编辑可手工保存 X、公众号等来源的标题、署名、链接、节选和可选原始日期；可从运营者预先配置的订阅或 X 单账号拉取。作者本人录入的原话单独存储、明确确认并保留定位。选题由本人确认，关联一条原话与多条外部证据。

## 数据与行为

规范化链接去片段，重复拉取保持唯一；同一选题归集多源，来源区与自述区分开。每个 X 账号独立游标，取完一轮后才推进。手工补录适用于无法获取的正文。

## 可观察验收

重复 URL 不产生新的材料；未经确认或他人的原话无法立项；抓取中断保留游标；原文时间未知时留空。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。
