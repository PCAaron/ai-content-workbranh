# 模块设计审核 · 2026-11-20

审查方式为同一实施者分轮对照规格和上游历史。以下 PASS 仅批准设计进入实现，用户署名意愿、生产账号和上线验收独立记录。

| 模块 | 走查发现与备选比较 | 实施约束及验收反例 | 决议 |
|---|---|---|---|
| 01 工作区 | 参考工作台按单机私有目录隔离。共享企业部署需要可撤销用户，与仅信任反代请求头相比，框架会话有清晰公私边界 | 关闭自助注册，认证、CSRF、角色由服务端检查。单租户部署，同组可见；生产用 PostgreSQL。验匿名、普通编辑尝试审批、账号停用 | PASS |
| 02 素材 | AIHOT 的账号水位与无日期修复说明单一全局游标会漏数据。粘贴链接不代表允许读取任意 URL | 运营者配置固定订阅，X 每账号独立增量；先存证据再推进游标。手工链接只做出处。原话与外部节选独立存储，以归属账号确认选题 | PASS |
| 03 写作 | 比较请求内生成与 worker。上游未知付费回执表明进程退出后简单重试会重复付费 | 领取使用条件更新，记录调用意图，外呼不占事务；未回包与本地保存冲突可诊断，最多两次生成。保留输入、改稿、恢复和审核历史。验并发与异常响应 | PASS |
| 04 渠道 | 参考仓库含官网接口和未公开接口；同属“推草稿”的按钮实际能力不同 | 公众号与 X 只准草稿 API；显式提示账号和成本；星球提供手动导入，小红书提供实际 PNG。按当前母稿及渠道修订校验，回执未知需人工核对 | PASS |
| 05 进化 | 对比自动覆写提示词、以同篇文章自评，与独立人工修订对回放。选择后者，先验证可执行措辞规则 | 留出稿必须与训练稿不同，展示各例基线与候选分；绑定评测时的生效规则，基线变更需重评。回滚保留证据和历次决定。不能由模型确认自身质量 | PASS |
| 06 工作区 | 参考编辑器注重原话、并排校对和移动屏；照搬 macOS 配音或另建公开热点门户都偏离本次工作流 | React 同源调用 Python；真实 API 持久化，浏览器走通主流程；部署手册区分本机、生产与账号联调。验证无密钥仍可执行编辑、渠道导出与学习 | PASS |

每个实现提交逐项映射规格；运行与账号验收见独立结果。
