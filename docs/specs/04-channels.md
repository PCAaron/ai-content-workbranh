# 04-channels · 渠道编译、图卡与草稿交付

## 业务契约

从经过审核的母稿派生公众号 HTML、X 长文、知识星球 Markdown、小红书配文和 PNG 卡。各渠道有可编辑标题与正文；平台与稿件版本一起保存。编辑后审核员确认具体版本，才能导出或显式建远端草稿。

## 数据与行为

纯文本转义后渲染；小红书以可编辑卡片文本渲染 PNG；X 和公众号使用配置的官方草稿端点，其他渠道导出。调用前落回执；同一版本重复请求返回同一条；未知状态待对账。

## 可观察验收

四渠道格式正确，PNG 可解码，旧母稿的派生稿禁止交付；编辑后重新审核；无配置清晰提示；外呼失败/未知可查，不自动公开发表。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。
