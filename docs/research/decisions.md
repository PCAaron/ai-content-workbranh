## Agent 运行与学习

[agent-autoloop](https://github.com/KKKKhazix/agent-autoloop) 提供持续处理工作和关键决策转人的参考。[Hermes Agent](https://github.com/NousResearch/hermes-agent) 提供跨会话经验与技能学习参考。[长任务 harness](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents) 着重可恢复的增量执行与验证。本项目以持久任务、有限反馈循环和受审核的写作规则分别落地。运行时选单个 Python worker 协议，避免两个调度器抢同一份工作。此决策只适用于这个新仓库，未推断任一上游 CLI 的兼容性。
