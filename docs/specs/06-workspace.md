# 06-workspace · React 编辑台与部署验收

## 业务契约

中文素材台、选题、稿件编辑、渠道、运行与文风，从空状态可完成整条流程。展示出处、原话、当前版本、操作结果及角色权限。移动端与键盘可用。

## 数据与行为

React 与构建工具打包本地静态资源，Python 同源托管；API 可单独测试。服务端为状态权威。运营文档覆盖环境、账号、worker、TLS、数据库、日志、备份恢复、上线与回退。

## 可观察验收

浏览器从登录到导出；刷新不丢已保存数据；窄屏可操作；真实模型、账号、作者署名及实际部署独立列项。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。

## 从远端复验

对 main 的 push 和 pull request，在干净的 Linux runner 以只读仓库权限安装锁定依赖，构建 React，核对迁移漂移，在独立 PostgreSQL 16 服务执行后端及 Chromium 端到端测试。同时执行 SQLite 的本机兼容检查。使用临时数据库凭据和合成内容，不配置真实模型或渠道。运行结论必须能追溯到具体提交和 Actions run。
