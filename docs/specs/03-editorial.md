# 03-editorial · 写作、编排与审稿

## 业务契约

人可手写母稿，或显式提交有限次数的模型任务。任务锁定选题证据、作者原话和文风规则。模型给出正文与引用；校验失败可将具体原因反馈给模型复写一次。编辑可批注、保存改稿理由、查看历史、恢复旧版。

## 数据与行为

独立 worker，数据库任务与尝试回执；先占有再出网。未知响应不自动重发。输出必须含作者原话和实际选题引用，模型输出只能作为待审版本。版本条件写防止并发覆盖；恢复追加新版本。审核绑定当前版。

## 可观察验收

无密钥可走完手工路径；模拟模型首轮缺引文、第二轮修复，超预算停；未知请求不重放；过期版本写入拒绝；已审核文章修改后原批准失效。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。
