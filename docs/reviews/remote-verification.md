# 远端复验设计审核

审核对象为 [工作区与部署验收 Spec](../specs/06-workspace.md) 的远端复验条款。单人审核通过，允许实现。

比较本机测试、GitHub 托管 runner 与真实生产域。托管 runner 能给新克隆提供独立证据，覆盖锁文件可安装性、数据库启停、中文字体与浏览器下载。本机测试提供故障定位和补充验证，真实域名与第三方授权另外验收。

走查时核对了 Python 和 Node 版本、PostgreSQL 服务就绪检查、字体路径、浏览器安装步骤、测试库创建权限及产物来源。工作流只需 contents: read，checkout 不保留凭据；测试用临时数据库、合成账户和受控响应。分别保留 SQLite / PostgreSQL 的检查结果。发布权限、定时触发和生产凭据均不属于该检查。
