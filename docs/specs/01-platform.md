# 01-platform · 工作区和运行环境

## 业务契约

一个部署服务一间编辑部。每人独立账号，编辑可建稿，审核员可批准、导出或提交平台草稿。使用 Django 会话、CSRF、密码哈希、数据库迁移；后台不向匿名读者开放素材。所有业务写入附操作者和事件。生产采用 PostgreSQL，单机验证支持 SQLite。

## 数据与行为

Django 内置认证与 ORM、数据库唯一约束；运营者通过管理命令配置角色。API 和同源 React 前端共享会话；生产开启 HTTPS cookie，密钥由环境注入。

## 可观察验收

匿名读写被拒、CSRF 生效、错误角色被拒；已保存记录关闭重开可读；生产配置检查、迁移和数据库备份可复核。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。
