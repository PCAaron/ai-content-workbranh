# 05-learning · 文风学习与受控进化

## 业务契约

修改前后差异与改稿理由是候选规则的训练证据。以编辑指定的短语替换形成可执行候选；系统从修改中建议候选。用不同文章的人工作品比对现行版本与候选版本，使评测可重复；审核员决定启用和退出。

## 数据与行为

仅对文风措辞进行确定性后处理；保护已确认原话及引用。评测使用已存储的独立修订对；要求至少一次改善且其余不退化，绑定现行基线；跨版本切换留历史。

## 可观察验收

训练稿不可充当留出样本；无改善或有退化阻止批准；启用后影响新任务，旧任务保持快照；回滚恢复上一基线。

实现前须对照参考仓库，审查失败路径、数据归属和平台边界。
