# 02b · 跨账号主题发现

编辑在素材与选题中选择 X 或微信公众号，输入主题和样本上限即可发现新来源。一次点击查一个平台、一个结果页，服务端有密钥即可使用。保留已有订阅和手工录入入口。

| 平台 | 采样框与上限 | 结果分析 | 进入来源库 |
|---|---|---|---|
| X | v2 recent search，最近七天，排除纯转发，10、20 或 50 条，按时间取样 | 去重帖数、可识别作者数、点赞/转发/回复/引用四项都有值的样本数及互动总数中位数；完整样本按互动总数降序 | 编辑选择单条，保存链接、API 文本、可用署名与原文时间 |
| 微信公众号 | Brave Web Search 单页，限定 mp.weixin.qq.com，近一周索引筛选，10 或 20 条；接受公开文章地址 | 去重文章数、有摘要的篇数、查询词在标题或摘要出现的篇数 | 只签发原文链接。编辑打开原文后填入核对的标题、可选节选。搜索摘要留在当前预览 |
 
结果需展示查询、采样时间、上限和口径。多个空格分隔的自然词按各平台搜索语法检索，分析中的词频按篇计。阅读、点赞等微信公众号后台数据不可由网页摘要推算。X 缺少指标时保留候选并排除出中位数；有效的零互动计入。

检索只允许已授权编辑或审核账号。每个检索动作带唯一请求号；外呼之前登记回执；同一请求号重放或中断不得重复外呼，不自动翻页或重试。回执只保存操作者、平台、时间、上限、状态和计数。预览在短时效内由同一用户选入，按原文地址去重。未选入候选不写来源库。

## 验收

1. 未填写任何账号、订阅或文章地址即可发起以上两路检索。空结果、未配置、上游失败分别可辨。
2. 验证恶意或无效地址、跟踪参数去重、样本上限、作者信息/指标缺失与零值、逐词篇数。
3. 重放请求、越权、篡改/过期入库凭据、重复入库、公众号摘要和可引用节选的边界均有接口用例。
4. 浏览器按主题发现、打开候选并选入来源库，复查既有稿件流程。凭证联调与合成响应验收分别报告。
