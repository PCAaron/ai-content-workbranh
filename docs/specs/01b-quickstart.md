# 01b · 本机一键启动

Windows 用户双击根目录 start.cmd，macOS/Linux 用户在仓库根目录执行 sh start.sh。宿主机只需已运行的 Docker 和支持 up --wait 的 Compose V2。首次构建需要联网。此入口服务单机编辑部试用，复用现有 React、Python Web 和模型 worker，保留现有生产部署入口。

- 一个动作完成前端构建、Python 依赖、中文字体、迁移、Web 与 worker 启动。Web 仅映射到 127.0.0.1:8000。两个进程共同使用持久 SQLite 卷。各安装持有独立的会话签名密钥。
- 首次启动由操作者设置具备审核能力的命名账号和密码。密码通过终端无回显输入，沿用账号命令验证。已有可登录的审核员时跳过开户；已有材料或账号不可重置。失败允许修正后重试。
- 启动成功显示地址，Windows 自动打开默认浏览器。失败时保留可见原因和非零退出码，不打开错误页面。停止后可用同一入口重开。
- 默认没有外部服务密钥。可选的采集和模型变量通过服务端环境配置。镜像构建不包含本地配置、密钥、数据或 Git 历史。当前原生部署的数据与 Compose 新卷各自保存。

## 验收场景

空白检出从同一入口开户，访问首页、加载 React、登录、核对审核角色。重复启动和 down 后重开，无需重设密码，原账号和素材可读。检查 worker 已启动、数据库迁移、中文字体和仅本机端口。缺 Docker、首次开户失败均应报告问题。Linux 实测完整容器流程；Windows 入口和真实桌面双击分别说明证据。
