# 04b · 模型化渠道改写

初次编译须在无模型时生成可编辑结构。对需要深度改写的工作，编辑可明确授权同一持久 worker，以审核母稿和选定渠道规则起草新版本。X 要有可独立阅读的开篇与后续论证；公众号使用导语、完整论证和收尾；星球强调经验与讨论；小红书给出短标题、可读配文和分卡。编辑可指定作者以往已审核的同署名文章作为风格样本。选取原文、外发边界和预算需可见。

同一个渠道版本的重复请求只登记一次，最多按预算尝试两次。模型回传结构、来源编号、长度和图卡数量要在写入前校验。渠道稿变动须清除批准；生成期间母稿、渠道稿有新版本时保留候选结果供比对。风格样本不能作为个人事实来源。验收以服务商协议模拟、重复请求、并发冲突与资源门禁为准。真实质量用作者试稿单列。
